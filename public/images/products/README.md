# 产品页面图片放置说明

## 图片位置
请将5个产品模块的图片放置在以下位置：

```
public/images/products/product-pricing.jpg     (产品定价)
public/images/products/bazi-destiny.jpg        (八字命理)
public/images/products/case-analysis.jpg       (案例分析)
public/images/products/marriage-compatibility.jpg (婚恋合盘)
public/images/products/2026-fortune.jpg        (2026运势分析)
```

## 图片要求
- **格式**: JPG 或 PNG 格式
- **尺寸**: 建议宽高比为 4:3 或 16:9，最小宽度 400px
- **文件大小**: 建议不超过 2MB
- **内容**: 与对应主题相关的高质量图片

## 布局说明
- **桌面端**: 第一行3个模块，第二行2个模块左对齐
- **移动端**: 单列垂直排列
- **悬停效果**: 图片放大、阴影增强、轻微上移

## 注意事项
1. 图片文件名必须严格按照上述命名
2. 如果图片加载失败，系统会显示占位符
3. 图片会自动适应容器尺寸，保持宽高比
4. 所有图片都有圆角和阴影效果
