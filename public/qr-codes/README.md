# 微信二维码图片说明

## 文件位置
请将您制作好的2个微信二维码图片放置在此目录下：

```
public/qr-codes/
├── zhengzhe.png    # 正哲师姐的微信二维码
├── dinghuo.png     # 丁火师妹的微信二维码
└── README.md       # 本说明文件
```

## 图片要求
- **文件格式**: PNG 格式（推荐）或 JPG 格式
- **图片尺寸**: 建议 200x200 像素或更高分辨率的正方形图片
- **文件大小**: 建议小于 500KB
- **图片质量**: 确保二维码清晰可扫描

## 文件命名
- 正哲师姐的二维码: `zhengzhe.png`
- 丁火师妹的二维码: `dinghuo.png`

## 注意事项
- 图片文件名必须与代码中的引用保持一致
- 确保图片路径为 `/qr-codes/文件名.png`
- 如果需要更改文件名，请同时修改 `src/app/consultation/page.tsx` 中的对应引用
