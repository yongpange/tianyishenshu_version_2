## 📧 2. 多渠道通知系统

### **通知方式配置**

```yaml
# .github/workflows/selenium-tests.yml 中的通知配置

# 邮件通知
- name: 📧 发送邮件通知
  if: always()
  uses: dawidd6/action-send-mail@v3
  with:
    server_address: smtp.gmail.com
    server_port: 587
    username: ${{ secrets.EMAIL_USERNAME }}
    password: ${{ secrets.EMAIL_PASSWORD }}
    subject: |
      ${{ job.status == 'success' && '✅' || '❌' }} 天乙神算自动化测试结果
    body: |
      测试状态: ${{ job.status }}
      提交信息: ${{ github.event.head_commit.message }}
      提交者: ${{ github.actor }}
      查看详情: ${{ github.server_url }}/${{ github.repository }}/actions/runs/${{ github.run_id }}

# 微信通知（通过企业微信机器人）
- name: 📱 发送微信通知
  if: failure()
  run: |
    curl -X POST "https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=${{ secrets.WECHAT_WEBHOOK }}" \
    -H "Content-Type: application/json" \
    -d '{
      "msgtype": "markdown",
      "markdown": {
        "content": "## 🚨 天乙神算测试失败\n\n**提交信息**: ${{ github.event.head_commit.message }}\n**提交者**: ${{ github.actor }}\n**时间**: $(date)\n\n[查看详情](${{ github.server_url }}/${{ github.repository }}/actions/runs/${{ github.run_id }})"
      }
    }'

# Slack通知
- name: 💬 发送Slack通知
  if: always()
  uses: 8398a7/action-slack@v3
  with:
    status: ${{ job.status }}
    channel: '#dev-team'
    text: |
      ${{ job.status == 'success' && '✅ 测试通过' || '❌ 测试失败' }}
      提交: ${{ github.event.head_commit.message }}
      作者: ${{ github.actor }}
```

## 🔔 5. 自定义通知规则

### **通知配置文件**

```yaml
# .github/workflows/notifications.yml

name: 智能通知系统

on:
  workflow_run:
    workflows: ["天乙神算自动化测试"]
    types: [completed]

jobs:
  notify:
    runs-on: ubuntu-latest
    steps:
    - name: 📊 分析测试结果
      run: |
        if [ "${{ github.event.workflow_run.conclusion }}" == "success" ]; then
          echo "TEST_STATUS=✅ 通过" >> $GITHUB_ENV
          echo "NOTIFY_LEVEL=info" >> $GITHUB_ENV
        else
          echo "TEST_STATUS=❌ 失败" >> $GITHUB_ENV
          echo "NOTIFY_LEVEL=urgent" >> $GITHUB_ENV
        fi
    
    - name: 📧 发送通知
      run: |
        # 根据时间和状态决定通知方式
        HOUR=$(date +%H)
        
        if [ "$NOTIFY_LEVEL" == "urgent" ]; then
          # 测试失败：立即通知所有渠道
          echo "发送紧急通知到所有渠道"
        elif [ $HOUR -ge 9 ] && [ $HOUR -le 18 ]; then
          # 工作时间：发送即时通知
          echo "发送工作时间通知"
        else
          # 非工作时间：只发送邮件，不打扰
          echo "发送非工作时间通知"
        fi
```

## 🎯 总结：完整的反馈循环

```
你提交代码
    ↓ (立即)
GitHub显示"正在检查"
    ↓ (2-3分钟)
测试完成，状态更新
    ↓ (同时)
多渠道通知发送
    ↓ (随时)
你可以查看详细报告
```

这样，你就能实时掌握每次代码提交的测试状态，再也不用担心"不知道测试进度"的问题了！🚀
